# Brix 浏览器自动化

业务插件通过 Brix HTTP API 向 Agent 提供通用浏览器能力，包括会话、导航、页面快照、
点击、填写、上传、截图、脚本执行和下载产物读取。Google Lens 只是插件附带的一份
服务端脚本，不是插件的能力边界。

插件不依赖 Brix MCP。Agent 通过插件内的命令行入口调用直接 HTTP SDK，图片和下载文件
都由命令行入口在本地读写，不要求模型把 base64 放入工具参数。

`assets/scripts/` 是受控 Brix 脚本目录。执行其中的脚本前，客户端先读取服务端同名脚本：
已存在时直接使用，只有明确返回 HTTP 404 时才保存插件附带的副本。鉴权失败、网络
失败和其他 HTTP 错误都会直接终止，不覆盖服务端现有脚本。

租户需要配置 `brix.base-url` 与 `brix.token` 两个 Secret。需要浏览器的空间选择本插件，
并开放 `skill_activate` 与 `shell`。具体业务要求由外部可信提示词传入，无需写入空间的通用提示词。
