# B 站视频分析业务插件

插件只支持 Linux amd64，包含 B 站链接解析、BBDown 下载、分区与视频信息读取，以及置顶和高赞评论整理。它依赖 `audio-video-tools` 提供 `ffmpeg`、`ffprobe`、关键帧抽取和 Speaches 转写，不再声明 Speaches Secret。本插件包直接包含 BBDown 可执行文件，不在运行任务中下载、解压或修改权限，最终由 RunForge Agent 进行分析。

每个任务先读取视频信息、下载实际音轨并转写，再读取置顶和少量高赞评论。视频卡片已经足以说明内容时静默结束；元信息无法说明内容时只返回简短概述；只有包含大量知识讲解、论证、推导或系统分析的视频进入详细分析。分类前和简短概述档不得读取画面或搜索。

详细分析只核验会影响视频核心结论且属于非常识的关键主张，视频作者和评论中的事实说法使用相同标准。外部证据支持原说法时不输出核验项；只有错误、片面、证据不足或仍无法确认时才提供精简纠正。延伸搜索只补充非领域读者理解核心论证所必需的前置知识。来源保存在结构化结果的 `sources` 字段供调用方内部核验，不放入用户可见正文。

发布前执行 `scripts/package-linux-amd64.sh <staging-directory>` 生成外层 TGZ。`bin/linux-amd64/BBDown` 必须已经存在；禁止在插件包内继续嵌套 ZIP、TGZ 或其他归档。
