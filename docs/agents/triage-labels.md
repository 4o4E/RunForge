# 工作项分流标签

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 尚待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充必要资料 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可由开发助手实施 |
| `ready-for-human` | `ready-for-human` | 需要人工操作或业务判断 |
| `wontfix` | `wontfix` | 已决定不处理 |

角色标签描述工作项准备状态，不表示 OpenSpec 提案已获批准、代码已部署或验收成功。`bug`、`enhancement`、`documentation` 等现有标签继续描述问题类别，不替代上述状态。

分流时先读取完整讨论、对应 OpenSpec 与现有实现，向用户说明证据和建议；仅在授权后修改远程状态。
